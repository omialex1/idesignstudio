# Project UI rules

- **Cards with text and a button: the button never moves.** In every card that has text and a button (category and subcategory cards, product cards, "Noutăți" / "Merge bine cu" cards, and any new card), the button (or the price and buttons row) is pinned to the bottom of the card. The text lives in its own area that grows and shrinks (`flex-1`, text centered inside it); a longer name takes more lines and never pushes the button. Cards in the same row have equal height, so their buttons line up. Check this for any new or changed card.
- All Romanian text on the site must have proper diacritics (ă â î ș ț).
